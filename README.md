# TNT Launcher

Лаунчер Minecraft: Java Edition для Android — для телефонов и планшетов.

## Возможности

- **Интерфейс для телефонов и планшетов**: в портретной ориентации новости сверху, управление снизу;
  в альбомной и на планшетах — новости слева, управление справа. Тёмная тема с оранжевым акцентом.
- **Мои версии**: в списке только установленные версии и сборки — их можно переименовывать и удалять
  (вместе с папкой или без). Кнопка «Скачать новую версию» открывает весь каталог: Релизы / Снапшоты /
  Бета / Альфа / Первоапрельские, сборки вперемешку с версиями — Fabric, Fabric+Sodium, Quilt, Forge,
  Forge+OptiFine, OptiFine, LiteLoader.
- **Работа без интернета**: установленные версии и сборки запускаются офлайн.
- **Скачать сборку**: готовые модпаки с Modrinth с выбором версии игры, загрузчика, названия и версии сборки.
- **Моды**: каталог Modrinth для выбранной сборки — поиск, установка в один клик вместе с зависимостями,
  вкладка «Установленные» с удалением.
- **Что нового**: официальные патч-ноуты Mojang с автопереводом; если их нет или нет интернета —
  собственные описания версий TNT Launcher.
- **Аккаунты**: Microsoft или офлайн-ник.
- **Автоустановка Java**: лаунчер сам скачивает нужную версию Java (8 / 17 / 21 / 25).
- **Изоляция версий**: у каждой сборки своя папка с мирами, модами и настройками.
- **Обход серой «Сетевой игры»** в 1.16.4/1.16.5 для офлайн-ника.
- **Язык интерфейса** в настройках: как в системе, русский, английский и ещё 15 языков.
- **Оптимизация**: стартовые настройки игры под мощность телефона (дальность прорисовки, симуляция,
  частицы, тени, mipmap, FPS = частота экрана), авто-выбор рендера по версии (до 1.17 — Krypton/GL4ES,
  новее — MobileGlues), флаги JVM против фризов, Sodium в один тап.
- Своя раскладка экранного управления по умолчанию; редактор — в меню «☰ Ещё».

## Сборка

Нужны JDK 17, Android SDK (platform 37, build-tools 36/37) и NDK 27.3.13750724.

```bash
git clone --recursive <адрес репозитория>
```

В Windows запустите `build_android.bat` — получится `TNTLauncher.apk`. Подробнее — в [android/README.md](android/README.md).

Иконка и фон берутся из `resources/label.webp` и `resources/Beground.webp`
(пересоздать: `tools/make_android_icons.ps1`).
