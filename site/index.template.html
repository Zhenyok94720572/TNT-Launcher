Установка

Четыре шага до первого мира

  1. Скачайте APK

    Нажмите «Скачать APK» вверху страницы — на телефоне файл TNTLauncher.apk попадёт в «Загрузки».

  2. Разрешите установку

    Откройте файл. Android спросит про «неизвестные источники» — разрешите установку для браузера или файлового менеджера.

  3. Войдите

    Нажмите на полосу аккаунта вверху лаунчера: аккаунт Microsoft или офлайн-ник.

  4. Выберите версию и играйте

    «Версия» → «Скачать новую версию», выберите версию или сборку и нажмите «Играть». Игра и Java скачаются сами.

Вопросы

Частые вопросы

Это бесплатно?

Да, лаунчер бесплатный. Сама Minecraft: Java Edition по правилам Mojang требует покупки — вход через аккаунт Microsoft подтверждает её.

Обновление удалит мои миры?

Нет. Новую версию лаунчера ставьте поверх старой: установки, миры, моды и настройки сохраняются.

Как поиграть с модами?

Установите сборку Fabric, Quilt или Forge, выберите её и нажмите «МОДЫ» — откроется каталог Modrinth для этой версии. Готовые модпаки — по кнопке «Скачать сборку».

Игра тормозит, что делать?

Выберите сборку Fabric+Sodium, уменьшите дальность прорисовки и разрешение в настройках лаунчера. Профиль устройства и авто-выбор рендера — в меню «☰ Ещё → Оптимизация TNT».

Где сообщить об ошибке?

В официальном Telegram-канале @tntlaunchermobile. Приложите лог: «☰ Ещё → Поделиться логом последнего запуска».
